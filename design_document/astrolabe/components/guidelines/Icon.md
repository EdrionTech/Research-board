# Icon

Icon draws one of the geometric celestial glyphs in `currentColor`. Every glyph is built from true circles, ellipses and straight lines on a 24px grid: 1.75px strokes, round ends, outlines only, with tiny solid moons, stars and nodes as the only fills.

- Provide `name`, optional `size` and `label` when it stands alone. Standalone icons (map markers, app icons) are the ready-made Orbs in Assets.
