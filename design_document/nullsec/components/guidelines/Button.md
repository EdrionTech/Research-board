# Button

Button is a chamfered command with an uppercase label and a trailing chevron.

- Provide a short verb as `children` ("Connect", "Hack", "Accept"); it's uppercased for you. Optional `icon`, `trailing` (another icon, or `false`), `variant`, `tone`, `size`.
- `solid red` is the one primary action per screen. `outline` for secondary actions, `ghost` for tertiary ones and cancel.
- `cyan` confirms or accepts; `amber` is for actions with a risk; red outline for destructive ones, always with a confirming word ("Delete file").
