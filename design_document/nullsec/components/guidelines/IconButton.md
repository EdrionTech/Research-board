# IconButton

IconButton is an octagonal button holding one glyph — for OK/close, toolbars and HUD controls.

- Provide `icon` and `label` (read aloud), optional `tone`, `size` (`sm` 32, `md` 40, `lg` 60) and `variant` (`solid` fills it).
- A big solid red octagon with `close` or `check` reads like the confirm dials in game HUDs; use one pair at most.
