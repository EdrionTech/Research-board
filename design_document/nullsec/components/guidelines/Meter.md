# Meter

Meter is a slanted, segmented bar with a label and a mono value — health, fuel, charge, signal.

- Provide `label`, `value` (0–100), optional `tone`, `icon`, `segments` (default 20) and `display` (custom value text, "100 L").
- Red for health and threat, cyan for energy and progress, amber when a value is low enough to act on.
