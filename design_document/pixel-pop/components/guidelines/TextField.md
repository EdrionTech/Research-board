# TextField

TextField is a cream well with a 2px outline; text is set in the `system` face (JetBrains Mono, 15px).

- Provide `label` (uppercase is applied), `placeholder`, optional `hint`, `error` (shows the warning icon plus `danger-ink` text), `icon` (a teal icon block on the left — use `search` for search boxes) and `multiline`.
- Errors always say what to do: "Name is too long — 12 letters max."
- Don't use placeholder text as the label.
