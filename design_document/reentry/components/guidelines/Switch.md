# Switch

Switch is a cockpit toggle: a ridged metal lever that slides along a slot, with a lamp and an ON/OFF stencil beside its label.

- Provide `label`, `checked`/`defaultChecked`, `onChange`, `disabled`, and optional `onText` / `offText` ("ARMED" / "SAFE"). It is a real switch for screen readers; the lamp and stencil are extra cues, so state never relies on colour.
