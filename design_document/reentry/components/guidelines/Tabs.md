# Tabs

Tabs are channel keys in a recessed rail. The selected key is pressed in and its lamp strip glows amber.

- Provide `tabs` (strings or `{label, icon}`), `value`/`defaultValue`, `onChange`, `label`, and `children` (or a function of the active index).
- Arrow keys, Home and End move between tabs. On narrow screens the rail scrolls sideways inside itself; the page never does.
