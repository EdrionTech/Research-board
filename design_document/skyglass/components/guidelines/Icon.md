# Icon

Icon draws one of the system's chunky, rounded 24px glyphs in `currentColor`, with a 1px embossed lip so it sits in the glass rather than on top of it.

- Provide `name`, optional `size` (16, 20, 24 or larger) and `label` if it stands alone.
- Use it inline beside text and inside buttons and orbs. For an icon that stands on its own, use IconBadge.
