# OrbButton

OrbButton is a round glossy bubble holding one icon.

- Provide `icon` and `label` (read by screen readers), optional `tone` (default `glass`) and `size` (`sm` 32, `md` 40, `lg` 56, `xl` 76).
- Media and navigation controls are orbs; the main play/pause is the only `lg` `blue` orb on screen.
- Group orbs in a row with `space-3` gaps.
