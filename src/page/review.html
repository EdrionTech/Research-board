Literature review

Cite with [@key], add a page or time with [@key, p. 4], cite several with [@a; @b], or name the authors in your sentence with @key. The reference list is added at the end automatically.

Citations show as they will appear: type @ (or [@ for brackets) to add one, or use the Sources tab. Double-click a citation to add a page or time; Backspace removes it. The reference list is added at the end automatically.

Insert adds the figure or table with its number (“Figure #” / “Table #” become Figure 1, 2… and Table 1, 2…), its title, and a credit note in the project's style (“From …” or “Adapted from …”); the source goes in the reference list. Save more with ★ or 📷 on a source's page.
